# 8-BIT COMPUTER
Design and FPGA implementation of an 8-bit Arithmetic Logic Unit (ALU) using Verilog on a Boolean board. The system executes six arithmetic and logical operations—addition, subtraction, AND, OR, XOR, and NOT—using 11 instructions, verified through simulation and hardware testing

# Instruction Set Architecture(ISA)

  OPCODE       -     INSTRUCTION
  
  0000         -    LDA address A
  0001         -    LDA address B
  0010         -    ADD     
  0011         -    SUB
  0100         -    AND
  0101         -    OR
  0110         -    XOR
  0111         -    NOT
  1000         -    STA address A
  1001         -    OUT
  1010         -    HLT
