# 8bit_ALU
Design and FPGA implementation of an 8-bit Arithmetic Logic Unit (ALU) using Verilog HDL on a Boolean board. The system executes six arithmetic and logical operations—addition, subtraction, AND, OR, XOR, and NOT—using 11 instructions, verified through simulation and hardware testing
